## Excalidraw Diagram Generator

**Skill instalada:** `github/awesome-copilot@excalidraw-diagram-generator`
**Installs globales:** 11.3K
**Comando de instalación:** `npx skills add github/awesome-copilot@excalidraw-diagram-generator -g -y`

### Qué hace
Genera archivos `.excalidraw` desde descripciones en lenguaje natural. El archivo se abre en excalidraw.com o con la extensión de VS Code.

### Tipos de diagramas disponibles
**Flowchart:** Flujo de registro de usuario, proceso de pago
**Arquitectura de sistema:** Cómo interactúan frontend, backend, DB
**Mapa mental:** Organizar ideas o conceptos
**Diagrama de relaciones:** Entidades y sus conexiones
**Diagrama ER:** Modelo de base de datos
**Diagrama de secuencia:** Flujo de mensajes entre componentes
**Swimlane:** Procesos multi-actor (cliente, sistema, admin)
**Diagrama de clases:** Diseño orientado a objetos

### Cómo usar
Pedirle al agente: *"Crea un diagrama de arquitectura de Aliax"*, *"Haz un flowchart del flujo de pago con Stripe"*, etc.
